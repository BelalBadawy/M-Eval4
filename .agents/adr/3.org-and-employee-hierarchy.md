# 3. Organization Structure & Employee Reporting Hierarchy Architecture

- **Status:** Accepted
- **Date:** 2026-09-05

## Context

Performance evaluation depends on an organizational model representing companies, departments, sections, and positions, as well as an employee reporting hierarchy where employees are assigned direct managers.

The design requires strict separation between application login credentials (`Users` — Module 1) and employee HR master records (`Employees` — Module 2). Additionally, organizational lookups are strictly mirrored from an upstream HR system and must have zero manual application CRUD.

## Decision

1. **Mirrored External Primary Keys (No Identity Generation):**
   - Entities `Companies`, `Departments`, `Sections`, `Positions`, and `Employees` use external integer IDs supplied by the HR system as primary keys (`CompanyId`, `DepartmentId`, `SectionId`, `PositionId`, `EmployeeId`).
   - Configured with EF Core `.ValueGeneratedNever()`.
   - Zero manual CRUD endpoints exist for organizational lookups; the sole writer is the synchronous HR synchronization import process.

2. **Database-Enforced Placement Matrix Integrity:**
   - Composite alternate keys: `Departments(DepartmentId, CompanyId)` and `Sections(SectionId, DepartmentId)`.
   - Composite foreign keys:
     - `Employees(DepartmentId, CompanyId) REFERENCES Departments(DepartmentId, CompanyId)` (`OnDelete: Restrict`).
     - `Employees(SectionId, DepartmentId) REFERENCES Sections(SectionId, DepartmentId)` (`OnDelete: Restrict`).
   - Check constraint `CK_Empl_SectionNeedsDept`: an employee cannot have a `SectionId` without a `DepartmentId`.
   - Check constraint `CK_Empl_StatusDates`: Active employees (`EmploymentStatus = 1`) must have `ResignationDate IS NULL`; Resigned/Terminated employees (`EmploymentStatus IN (2, 3)`) must have `ResignationDate IS NOT NULL`.
   - Check constraint `CK_Empl_ResignationAfterHire`: `ResignationDate IS NULL OR ResignationDate >= HireDate`.

3. **Self-Referencing Hierarchy & Overlaid Graph Cycle Detection:**
   - `DirectManagerId INT NULL REFERENCES Employees(EmployeeId)` (`OnDelete: Restrict`).
   - Top-level executives (`NLevel = 1`) are expected to have `DirectManagerId = null`.
   - Cycle detection evaluates the overlaid graph (`file rows ∪ existing DB employees`) to prevent cyclical reporting loops of any depth before persisting changes.
   - Manager traversal depth is capped at 100 hops to prevent infinite loops in queries.
   - Anomaly query evaluates orphans (`DirectManagerId == null && NLevel > 1`), root-with-manager anomalies (`DirectManagerId != null && NLevel == 1`), and manager status/company mismatches.

4. **Dual Identity & Local Column Ownership:**
   - `UserId INT NULL REFERENCES Users(Id)` (`OnDelete: Restrict`) with unique filtered index `UX_Employees_UserId WHERE UserId IS NOT NULL`.
   - Linking verifies that target user exists and has `IsActive = true`; double-linking returns `409 Conflict`.
   - Local-only columns: `IsEvaluationEligible`, `UserId`, and `IsActive` are locally owned and preserved across HR import updates.

5. **Offboarding Cascade:**
   - When an employee's status changes to `Resigned (2)` or `Terminated (3)` via import, any linked `User` account is deactivated (`IsActive = false`), its active refresh token is revoked (`RevokedReason.EmployeeOffboarded`), and an audit log (`EmployeeOffboarded`) is written.

6. **Synchronous Import Engine:**
   - Synchronous execution with file payload (`POST /api/v1/org/imports/execute`).
   - Single in-memory `SemaphoreSlim(1, 1)` concurrency lock shared between dry-run and execute (`409 Conflict`).
   - Lookup rules: renames allowed and propagated; re-parenting rejected as row errors; lookups never auto-deactivated.
   - Employee rules: `EmployeeId` is the upsert join key; `EmployeeNumber` is immutable; `Email` pre-validated for active uniqueness; absent employees untouched; single atomic `AllOrNothing` transaction.

## Consequences

- Structural placement integrity (department in company, section in department) is guaranteed at the database engine level.
- Cycle detection guarantees directed acyclic graph (DAG) structure for Module 5 evaluator routing.
- Deactivating or offboarding employees immediately terminates linked user sessions, mitigating unauthorized access risks.
